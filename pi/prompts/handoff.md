# Handoff

Next goal (if given): $ARGUMENTS

Produce a concise continuation summary for a fresh pi session. Include only what
the next session needs; omit process narration.

## Objective
Current goal and why it matters.

## Completed
What is done and verified.

## Decisions
Important choices made and why (including alternatives rejected).

## Files changed
Paths created/modified/deleted, one line each on what changed.

## Problems / blockers
Open bugs, uncertainties, failing checks, or needed input.

## Remaining work
Concrete next tasks, in order.

## Recommended next step
The single best next action, with the exact command or file to start from.
